🚀 Migrar Imágenes ibb.co → Supabase Storage

Descarga automáticamente todas las imágenes de ibb.co y las sube a Supabase Storage CDN, luego actualiza las URLs en la base de datos.

⚠️ Pasos antes de ejecutar:
  1. Sube al Plan PRO de Supabase ($25) — necesitas el Storage de 100 GB
  2. Ve a Supabase → Storage → New Bucket → nombre: product-images → marcar como Public
  3. Ve a Supabase → Project Settings → API → copia la service_role key (NO la anon key)
  4. Abre este archivo en el navegador, pega los datos y haz clic en Iniciar
